# ดีไซน์ของแอปมือถือ — ใช้ชุดเดียวทั้งแอป

**หน้าต้นแบบคือ 5 จอนี้** ถ้าจะทำจอใหม่หรือแก้จอเก่า ให้เปิดดูก่อนเสมอ

| จอ | ไฟล์ | เอาไว้ดูเรื่อง |
|---|---|---|
| หน้าหลัก | `src/app/(app)/(tabs)/today.tsx` | โครงจอ · การ์ดพระเอก · แถบทางลัดสี · การ์ดสรุป |
| ลงเวลา | `src/app/(app)/(tabs)/attendance.tsx` | หัวจอธรรมดา · ตัวสลับเดือน · หัวข้อย่อยมีตัวเลขท้ายบรรทัด |
| อนุมัติ | `src/app/(app)/(tabs)/approvals.tsx` | ชิปตัวกรอง · แถบค้นหา · รายการแถวยาว · สถานะว่าง/ผิดพลาด |
| คำขอ | `src/app/(app)/(tabs)/requests.tsx` | ปุ่มกลมบนหัวจอ · จัดกลุ่มรายการ · Sheet ตัวกรอง · โหลดเพิ่ม |

**ผิว "ออโรรา" (`@/design/aurora`) คือผิวของทั้งแอป ไม่ใช่ข้อยกเว้นของหน้าหลักอีกแล้ว**
จอที่ยังใช้ `<Screen>` กับสีจาก `useAppTheme()` คือจอที่ยังไม่ได้ย้าย ไม่ใช่จอที่ตั้งใจให้ต่าง

## 1. โครงจอ — เหมือนกันทุกจอ

```tsx
<View style={{ backgroundColor: AURORA.base, flex: 1 }}>
  <AuroraBackground />

  <SafeAreaView edges={['top', 'left', 'right']} style={{ flex: 1 }}>
    <ScrollView
      contentContainerStyle={{
        gap: 20,              // 18 ได้ถ้าบล็อกเยอะและสั้น
        paddingBottom: 36,    // 116 เมื่อมีปุ่ม/แถบลอยอยู่ล่างจอ
        paddingHorizontal: 18,
        paddingTop: 34,
      }}
      refreshControl={
        Platform.OS === 'web' ? undefined : (
          <RefreshControl
            onRefresh={() => void query.refetch()}
            refreshing={query.isRefetching}
            tintColor={AURORA.textMuted}
          />
        )
      }
      showsVerticalScrollIndicator={false}
    >
```

ตัวเลขสามตัวนี้ห้ามเปลี่ยนรายจอ: `paddingHorizontal: 18` · `paddingTop: 34` · `paddingBottom: 36`
สลับจอแล้วขอบต้องไม่ขยับ

`paddingTop: 34` เผื่อไว้สำหรับเครื่องที่ safe-area inset ด้านบนเป็น 0 (Android ส่วนใหญ่
ที่แอปไม่ได้วาดใต้แถบสถานะ) — ค่าต่ำกว่านี้ทำให้หัวจอไปแปะขอบบนจนอึดอัด
จอที่มีหัวจอตรึงอยู่นอก `ScrollView` (เช่นหน้ายื่นคำขอ) ให้ใส่ค่านี้ที่หัวจอแทน

**แถบสถานะ** — จอเป็นฟ้าอ่อนตลอดทั้งสองโหมด ตัวหนังสือบนแถบสถานะจึงต้องเป็นสีเข้ม
และต้องคืนค่าตามธีมจริงตอนออกจากจอ (คัดลอกจาก `today.tsx` ได้ทั้งก้อน):

```tsx
const auroraStatusBarStyle = useVisibleStatusBarStyle('dark');
const themeStatusBarStyle = useVisibleStatusBarStyle(resolvedMode === 'dark' ? 'light' : 'dark');

useFocusEffect(
  useCallback(() => {
    setStatusBarStyle(auroraStatusBarStyle);
    return () => setStatusBarStyle(themeStatusBarStyle);
  }, [auroraStatusBarStyle, themeStatusBarStyle]),
);
```

**`RefreshControl` ต้องกันเว็บทุกครั้ง** — `react-native-web` ส่ง prop ลงไปเป็น attribute ของ DOM
แล้วขึ้น error แดงคาจอตอน dev

## 2. หัวจอ

```tsx
<Reveal>
  <View style={{ gap: 3, paddingHorizontal: 4 }}>
    <Text style={{ color: AURORA.text }} variant="h1">ลงเวลา</Text>
    <Text style={{ color: AURORA.textMuted }} variant="caption">
      บันทึกเวลาเข้าออกและตรวจสอบรอบเงินเดือน
    </Text>
  </View>
</Reveal>
```

มีปุ่มเดียวได้ที่มุมขวา เป็นวงกลม/สี่เหลี่ยมมน **46×46** พื้น `AURORA.accent` ไอคอนขาว
พร้อมเงาสีเดียวกับปุ่ม (`shadowColor: AURORA.accent`, opacity ~0.2–0.24, radius 8–9)
ถ้าสิทธิ์ยังไม่เปิด ให้เป็นวงพื้น `accentSoft` ไอคอนกุญแจสี `textFaint` — **ห้ามซ่อนปุ่มทิ้ง**

`paddingHorizontal: 4` คือระยะที่ทำให้ตัวหนังสือ "นอกการ์ด" เรียงตรงกับเนื้อหาในการ์ดพอดี
ทุกอย่างที่วางบนพื้นฟ้าโดยตรง (หัวจอ, หัวข้อย่อย) ต้องมีค่านี้

## 3. หัวข้อย่อยของแต่ละบล็อก

```tsx
<View style={{ alignItems: 'flex-end', flexDirection: 'row', gap: 12, paddingHorizontal: 4 }}>
  <View style={{ flex: 1, gap: 2 }}>
    <Text style={{ color: AURORA.text }} variant="h2">รายการลงเวลา</Text>
    <Text style={{ color: AURORA.textMuted }} variant="caption">เรียงวันที่ล่าสุดก่อน</Text>
  </View>
  <Text style={{ color: AURORA.accent }} variant="bodyStrong">12 รายการ</Text>
</View>
```

ขวาสุดเป็นได้สองอย่างเท่านั้น: **ตัวเลขจำนวน** (สี accent, `bodyStrong`) หรือ **`<SectionAction>`**
(ข้อความฟ้า + ลูกศร) — ห้ามเอาปุ่มเต็มใบไปวาง

## 3.5 หนึ่งจอ = หนึ่งผิว

**ห้ามแบ่งจอเป็นสองสีพื้น** (เช่นหัวจอสีเข้ม + เนื้อหาสีขาว) ไม่ว่าจะดันให้ทับกัน
หรือไล่สีให้จางแค่ไหน ตาก็ยังอ่านเป็นสองบล็อกอยู่ดี — ลำดับของจอต้องมาจาก
**ขนาดตัวหนังสือกับเส้นคั่น** ไม่ใช่จากสีพื้น

ทุกหมวดอยู่ในผิวเดียวกัน **แบ่งด้วยระยะห่าง ไม่ใช่เส้นคั่น** — ช่องไฟระหว่างหมวด
ต้องมากกว่าช่องไฟภายในหมวดอย่างน้อยสองเท่า (ที่ใช้จริงคือ 36 กับ 12)

การ์ดลอยหลายใบเรียงกันทำให้จอกลายเป็นกล่องซ้อนกล่อง ส่วนเส้นคั่นทุกหมวดทำให้จอ
กลายเป็นตารางที่ถูกซอยเป็นแถบ ๆ — ทั้งสองอย่างเพิ่มขอบให้สายตาต้องข้ามโดยไม่ได้
บอกอะไรที่ระยะห่างบอกไม่ได้

คอมโพเนนต์ของแต่ละหมวด (`RequestsPanel` `PeriodPanel` `LeavePanel` `QuickRow`)
จึงคืนเนื้อล้วน **ห้ามห่อ `<Glass>` ของตัวเอง** — จอเป็นคนประกอบผิวให้

ของที่มีพื้นของตัวเองได้มีอย่างเดียวคือแถบเตือน (`NoticePanel`) และเป็น
**พื้นสีจาง** ไม่ใช่การ์ดที่มีขอบกับเงา

## 4. การ์ด — มีแบบเดียวคือ `<Glass>`

`<Glass>` มุม 28 ขอบฟ้าจาง มีแสงตกบนผิวบน **ห้ามเขียนการ์ดเอง ห้ามใช้ `<Card>` ของ `@/design`**
บนจอออโรรา และ **ห้ามซ้อน Glass ใน Glass** — ถ้าต้องแบ่งส่วนในการ์ด ให้คั่นด้วยเส้น:

```tsx
<View style={{ borderTopColor: AURORA.glassBorder, borderTopWidth: 1, marginTop: 18, paddingTop: 18 }}>
```

ระยะขอบในการ์ด:

| ใช้ทำอะไร | ค่า |
|---|---|
| การ์ดเนื้อหาทั่วไป | `padding: 16` หรือ `18` |
| การ์ดที่เป็นรายการ | `paddingHorizontal: 0, paddingVertical: 2` แล้วให้แต่ละแถวคุม padding เอง |
| สถานะว่าง | `paddingHorizontal: 18–22, paddingVertical: 30` |

`glow` ใส่เฉพาะการ์ดพระเอกของจอ (เช่นสลิปงวดปัจจุบัน) และต้องเป็นสีของของที่อยู่ในการ์ด

## 5. อนิเมชันขาเข้า

ทุกบล็อกบนจอห่อด้วย `<Reveal>` ไล่ delay ลงล่าง: `0 → 60 → 120 → 180 → 240`
ถ้าจำนวนบล็อกไม่แน่นอนใช้ `delay={120 + index * 90}`

`PressableScale` ใช้กับของที่กดแล้วไปที่อื่น (แถวรายการ, ปุ่มกลม, ลิงก์)
`Pressable` ธรรมดาใช้เมื่อต้องการไฮไลต์พื้นตอนกด (`rgba(37, 99, 235, 0.06)`)

## 6. สี — หยิบจาก `AURORA` เท่านั้น

**โทนของแอปคือ ฟ้าเป็นพื้น ขาวเป็นของที่ลอยขึ้นมา**

| ชั้น | สี | ใช้กับ |
|---|---|---|
| พื้น (เห็นมากที่สุด) | `base` `#c6ddfb` | พื้นของทุกจอ |
| ของที่ลอยขึ้นจากพื้น | `baseDeep` `#ffffff` / `glass` | การ์ด แถบล่าง ปุ่มไอคอน เม็ดบนเส้นเวลา |
| สีเดียวของแอป | `accent` `#1a45bd` | ปุ่ม ตัวเลขสำคัญ ลิงก์ ไอคอน |
| ของที่ต้องลอยบนพื้นฟ้า | `onBaseFill` `onBaseTrack` (ขาวโปร่ง) | ราง ชิป วงไอคอน ที่วางบนพื้นจอ |
| สัญญาณ (ใช้น้อยมาก) | `amber` `rose` | เฉพาะตอนต้องลงมือทำ |

**ห้ามเอาขาวไปเป็นพื้นทั้งจอ** — พอทั้งจอขาว แอปอ่านเป็น "แอปสีขาว" ไม่ใช่แอปโทนฟ้า
และของสีขาวที่วางทับก็ไม่เหลืออะไรให้ลอย ขาวต้องเป็นของหายากในจอถึงจะทำงาน

**ห้ามใช้ฟ้าจางเป็นพื้นของของที่วางบนพื้นจอ** — `accentSoft` มีไว้สำหรับของที่อยู่
บนการ์ดขาวเท่านั้น เอามาวางบนพื้นฟ้าเมื่อไรก็กลายเป็นสีเดียวกับพื้นจนหายไป
ของที่ต้องลอยขึ้นจากพื้นฟ้าใช้ `onBaseFill` / `onBaseTrack` ซึ่งเป็นขาวโปร่ง

ตัวอักษรทุกตัวถูกเลือกจากคอนทราสต์ **กับพื้นฟ้า** ไม่ใช่กับขาว ทั้งชุดผ่าน 5:1 ขึ้นไป

| | บนฟ้า | บนการ์ดขาว |
|---|---|---|
| `text` `#101828` | 12.79 | 17.75 |
| `textMuted` `#485265` | 5.67 | 7.86 |
| `textFaint` `#4e5a6d` | 5.03 | 6.98 |
| `accent` `#1a45bd` | 5.76 | 7.98 |
| `sky` `#075985` | 5.45 | 7.56 |
| `amber` `#973f04` | 5.00 | 6.93 |
| `rose` `#a80f34` | 5.44 | 7.55 |

**ถ้าจะทำพื้นให้ฟ้าเข้มกว่านี้ ต้องคำนวณคอนทราสต์ของทุกสีตัวอักษรใหม่ทั้งชุด**
ไม่ใช่เปลี่ยนแค่พื้น — ทุกครั้งที่พื้นเข้มขึ้นหนึ่งระดับ ตัวหนังสือต้องเข้มตาม


**บนจอออโรราห้ามใช้ `tone="muted"` / `theme.colors.*`** เพราะโหมดมืดจะได้ตัวหนังสือสีอ่อน
บนกระจกขาว ให้เขียน `style={{ color: AURORA.textMuted }}` เสมอ

| ใช้กับ | ค่า |
|---|---|
| ตัวหนังสือหลัก | `AURORA.text` |
| คำอธิบาย | `AURORA.textMuted` |
| meta / ของที่ไม่สำคัญ / ขีดคั่น | `AURORA.textFaint` |
| accent เดียวของแอป (ปุ่ม ตัวเลขสำคัญ ลิงก์ ไอคอน) | `AURORA.accent` |
| พื้นจางของวงไอคอน/ชิป | `AURORA.accentSoft` |
| ค่ารองที่ต้องแยกจากตัวเลขหลักโดยไม่หลุดโทน (OT, "รออนุมัติ") | `AURORA.sky` |
| เส้นขอบและเส้นคั่นทุกเส้น | `AURORA.glassBorder` |

**`amber` กับ `rose` ใช้ได้เฉพาะตอนผู้ใช้ต้องลงมือทำอะไร** — มาสาย ขาดงาน เวลาไม่ครบ
โควตาใกล้หมด ใบที่ถูกตีกลับ ของค้างส่ง
ห้ามใช้กับของที่แค่ "ดี" หรือ "ปกติ" (มาตรงเวลา ยอดเงิน วันลาที่เหลือเยอะ = ฟ้าทั้งหมด)
**หนึ่งแถวให้สีได้ตัวเดียว** ที่เหลือเป็นเทา/ดำ

## 6.5 ไอคอน — ชุดเดียวคือ Feather ผ่าน `<Icon>` เท่านั้น

```tsx
import { Icon } from '@/design';
<Icon color={AURORA.accent} name="sun" size={21} />
```

**ห้าม `import Ionicons from '@expo/vector-icons/Ionicons'` ในจอใหม่**
Ionicons ผสมสองบุคลิกในชุดเดียว บางตัวเส้นบางมน บางตัวหนากว่าและปลายตัด
พอวางเรียงกันสี่ห้าตัวบนจอเดียวน้ำหนักเส้นจะไม่เท่ากันจนดูเหมือนคนละชุด
Feather เป็นเส้น 2px เท่ากันทุกตัว ตารางฐาน 24 เหมือนกันหมด

Feather **ไม่มีตัวทึบ** — สถานะ "กำลังเลือกอยู่" (แท็บล่าง ชิปตัวกรอง)
ต้องบอกด้วยสี ห้ามสลับเป็นไอคอนทึบ

ขนาดที่ใช้: 17 (แถวรายการ) · 19–21 (ปุ่มไอคอน) · 23 (ทางลัด)

จอที่ยังเรียก `Ionicons` ตรง ๆ คือจอที่ยังไม่ได้ย้าย ให้เปลี่ยนตอนที่แตะจอนั้น

## 7. ตัวหนังสือ

ใช้ `<Text>` จาก `@/design` เสมอ ไม่ใช่ `Text` ของ react-native
variant ที่มี: `display · h1 · h2 · h3 · body · bodyStrong · caption · label · button`

- ตัวเลข/ค่าที่อยู่ในแถวแคบ ให้ใส่ `maxScale={1.1}`–`{1.2}` กัน layout แตกตอนผู้ใช้ตั้งฟอนต์ใหญ่
  แต่ห้ามใส่ `maxScale` กับข้อความยาว ๆ (ปล่อยให้ขยายได้ตามระบบ)
- แถวเดียวจบให้ใส่ `numberOfLines={1}` คู่กันเสมอ
- ตัวเลขเงินและเวลาที่เดินอยู่ ใช้ `fontVariant: ['tabular-nums']` ไม่งั้นทั้งแถวขยับ

## 8. แถวในรายการ

```
[ ไอคอนในวงพื้น accentSoft 38–44 ]  [ ชื่อเรื่อง + meta + สถานะ ]  [ ค่า ]  [ chevron ]
```

- `minHeight: 76–78`, `paddingHorizontal: 14–15`, `gap: 11–12`
- ชื่อเรื่อง `fontSize: 14, fontWeight: '600'`, meta `fontSize: 11` สี `textMuted`
- เส้นคั่นใช้ `borderTopWidth` ของแถวถัดไป (`divider={index > 0}`) สี `AURORA.glassBorder`
  ห้ามใช้ `<View>` เส้นแยก และห้ามมีเส้นบนแถวแรก/ล่างแถวสุดท้าย
- chevron ปิดท้ายเสมอถ้าแตะแล้วไปที่อื่น สี `AURORA.textFaint` ขนาด 17–19

**ป้ายสถานะ = จุดกลม 5px + ข้อความสีเดียวกัน** (`fontSize: 10.5, fontWeight: '700'`)
ไม่ใช่ป้ายพื้นทึบ — ป้ายพื้นทึบสงวนไว้ให้ "ประเภท" (พื้น `accentSoft` มุมกลม 999)

## 8.5 รายการยาวต้องใช้ `FlatList` ไม่ใช่ `.map()` ใน `ScrollView`

จอที่รายการโตได้ไม่จำกัด (แจ้งเตือน · คำขอ · อนุมัติ) ให้ `FlatList` เป็นตัวเลื่อน
ของทั้งจอ แล้วยกหัวจอกับแถบตัวกรองไปไว้ใน `ListHeaderComponent`

`<Glass>` ครอบทั้งรายการไม่ได้เพราะต้องเรนเดอร์ลูกครบทุกตัว — ใช้ `listCardEdge(index, total)`
ให้แต่ละแถววาดขอบของตัวเองแล้วต่อกันเป็นการ์ดใบเดียว และส่ง `divider={false}`
ให้แถว เพราะเส้นบนของแถวถัดไปทำหน้าที่เป็นเส้นคั่นอยู่แล้ว

กลุ่มในรายการ (หัวข้อวัน/หมวด) ต้องแบนรวมเป็น item ชุดเดียวกับแถว ไม่ใช่เก็บเป็น
"กลุ่มที่มีลูกข้างใน" — ไม่งั้นทั้งกลุ่มถูกเรนเดอร์พร้อมกันอยู่ดี

ค่าที่ใช้: `initialNumToRender` 10–12 · `maxToRenderPerBatch` 10 · `windowSize` 7 ·
`removeClippedSubviews` · `renderItem` ห่อ `useCallback` และอย่าให้ dependency
เป็นอาร์เรย์ที่สร้างใหม่ทุกเรนเดอร์ (React Compiler จะเลิก optimize ทั้งคอมโพเนนต์)

**อนิเมชัน `<Reveal>` ใส่ได้เฉพาะ `ListHeaderComponent`** ห้ามห่อแถว — แถวถูกใช้ซ้ำ
ตอนเลื่อน จะเห็นเป็นกะพริบทุกครั้งที่ recycle

## 9. ตัวกรอง — **ไม่มีตัวเลือกคาอยู่บนจอเลย ทุกอย่างอยู่ใน `<Sheet>`**

บนจอมีได้แค่ **แถบค้นหาแถบเดียว** ในการ์ด Glass พร้อมตัวเลขจำนวนตัวกรองที่เปิดอยู่ในวงกลม accent
แตะแล้วเปิด Sheet — ห้ามมีแถวชิป ห้ามมี segmented ห้ามมีแถวเลื่อนของประเภทบนจอ
เนื้อที่หัวจอเป็นของเนื้อหา ไม่ใช่ของตัวควบคุมที่ผู้ใช้แตะนาน ๆ ครั้ง (ดูแท็บอนุมัติกับคำขอ)

ตัวเลือกใน Sheet เป็นปุ่มมนเรียงพับบรรทัด:
```tsx
backgroundColor: active ? AURORA.accent : pressed ? AURORA.accentSoft : 'transparent',
borderColor:     active ? AURORA.accent : AURORA.glassBorder,
borderRadius: 999, borderWidth: 1, minHeight: 38, paddingHorizontal: 13,
```
ตัวที่เลือกอยู่ตัวอักษรขาว ที่เหลือ `AURORA.textMuted`
ในหัวข้อย่อยของ Sheet ใช้ `<Text variant="label">` และแยกกลุ่มด้วย `gap: 18`

ค่าที่เลือกอยู่ใน Sheet เก็บเป็น `draft*` แยกจาก `filters` จริง แล้วค่อยยัดเข้าตอนกด "ใช้ตัวกรอง"
— ไม่งั้นทุกครั้งที่แตะตัวเลือกจะยิง query ใหม่

**`<Sheet>` มีพื้นมืดข้างหลังเสมอ** (`dimBackground` ค่าเริ่มต้นเป็น `true`)
และตัวแผ่นมีเงายกขึ้นจากขอบล่าง — ของที่เด้งขึ้นมาต้องดูลอยเหนือจอ ไม่ใช่ต่อเป็นเนื้อเดียวกับพื้นข้างหลัง เปิดปิดได้ด้วย prop เฉพาะแผ่นที่ผู้ใช้ต้องเห็นของข้างหลังไปพร้อมกันจริง ๆ

**ตัวกรองที่เหลือทั้งหมดอยู่ใน `<Sheet>`** เปิดจากแถบค้นหาแถบเดียวในการ์ด Glass
พร้อมตัวเลขจำนวนตัวกรองที่เปิดอยู่ในวงกลม accent — ห้ามวางฟอร์มกรองคาไว้บนจอ

## 10. โหลด / ว่าง / ผิดพลาด — อยู่ใน `<Glass>` ทั้งสามสถานะ

| สถานะ | ใช้ |
|---|---|
| กำลังโหลด | `<Skeleton height={…} radius={18} />` หรือ `<SkeletonList rows={4} />` ใน Glass `padding: 16–18` |
| ว่าง | ไอคอนสี accent 30–36 → `bodyStrong` บอกว่าว่าง → `caption` บอกว่าของจะมาเมื่อไร (จัดกลาง) |
| ผิดพลาด | `bodyStrong` "โหลด…ไม่สำเร็จ" → `caption` ข้อความจาก `ApiError` → `PressableScale` ข้อความ "ลองใหม่" สี accent |

**ห้ามซ่อนการ์ดทั้งใบเมื่อไม่มีข้อมูล** — ผู้ใช้แยกไม่ออกระหว่าง "ไม่มีข้อมูล" กับ "ระบบพัง"

## 11. เงิน

- ผ่าน `money()` จาก `@/features/payroll/payslip.types` เสมอ และต่อท้ายด้วย ` บาท` ทุกที่
- ยอดสุทธิของงวด = `variant="h1"` สี `AURORA.accent` มีป้าย `caption` ว่า "รับสุทธิ" อยู่ข้างบน
- รายการหักในแถบสัดส่วนใช้ `AURORA.textFaint` **ไม่ใช่สีแดง** — การถูกหักภาษีไม่ใช่ความผิดพลาด
- บรรทัดรายรับ/รายหักในการ์ด: ป้ายซ้าย `caption` สี `textMuted` · ค่าขวา `caption` `fontWeight: '600'`
  แล้วปิดท้ายด้วยแถวรวมที่คั่นเส้น `glassBorder` เป็น `bodyStrong` ทั้งสองฝั่ง

## ของที่ยังไม่ตรง (แก้เมื่อแตะจอนั้น อย่าปล่อยเพิ่ม)

1. **`<Sheet>` ยังใช้สีจาก `theme`** — บนโหมดมืดแผ่นจะเป็นสีเข้มขณะที่จอข้างหลังเป็นฟ้าอ่อน
2. **Sheet ของหน้าคำขอเขียนด้วย `theme.colors.*` แต่ของหน้าอนุมัติเขียนด้วย `AURORA.*`**
   ยึดของหน้าอนุมัติ
3. จอที่ยังไม่ย้ายมาผิวออโรรา: `overview` · `schedule` ·
   `documents*` · `complaints*` · `team*` · `(auth)/verify-2fa`
   (จอ `executive-*` ย้ายครบแล้วทั้งหกจอ — ใช้ผิวขาว `PageHero` + `PageSection`)
